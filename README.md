# Doppler Effect

A small [Bevy](https://bevyengine.org/) demo of the Doppler effect. An ambulance drives past you with a looping siren — move your head (camera) to hear the pitch shift as it approaches and recedes.

## Run

```bash
cargo run
```

- **Mouse** — look around
- **Esc** — quit

## Requirements

- Rust (2024 edition)
- Audio output
